# 💰 PocketSmart AI

## Your Smart Budget & Recommendation Assistant

PocketSmart AI is a simple web-based financial assistant that helps users manage their income and expenses.

## Features

- Track monthly income
- Calculate total expenses
- Calculate remaining balance
- Suggest savings
- Provide smart spending recommendations
- Simple and user-friendly interface
- Mobile-friendly design

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The user enters their monthly income and expenses.

The application calculates the total expenses and remaining balance.

The recommendation system analyzes the user's spending level and provides a suitable financial suggestion.

## Purpose

The main purpose of PocketSmart AI is to help students and individuals develop better budgeting and saving habits.
